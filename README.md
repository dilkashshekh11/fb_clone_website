# fb_clone_website

This project is a **Facebook Clone Website** developed as part of my learning and practice in web development, Git, and GitHub. The main purpose of this project was to understand how modern websites are structured and to gain practical experience in managing a project using proper version control practices.

The website is inspired by the basic layout and user interface of Facebook. It focuses on recreating common social media interface elements such as navigation sections, user profiles, posts, feeds, and other familiar components.

While developing this project, I also focused on learning how to use **Git and GitHub properly**. I practiced creating repositories, making commits, writing meaningful commit messages, managing changes, working with branches, pushing code to GitHub, and maintaining a clean project history.

## 🎯 Purpose of the Project

The main objectives of this project were:

* To practice frontend web development.
* To understand how social media interfaces are structured.
* To improve my HTML, CSS, and JavaScript skills.
* To learn proper Git and GitHub workflows.
* To practice creating meaningful commits and tracking changes.
* To understand how to manage a project using GitHub.
* To gain practical experience by building a project from scratch.

## 📚 What I Learned

Through this project, I gained practical experience in both web development and version control. I learned how to organize a project, manage files, track development changes, and maintain the project using Git.

I also learned how to:

* Create and manage commits.
* Write meaningful commit messages.
* Connect a local project with GitHub.

## 🚀 Project Status

This project was created primarily for **learning and practice purposes**. It is not intended to be an exact copy of Facebook or a production-ready social media platform. The project may be improved and expanded with additional features as I continue learning web development.
